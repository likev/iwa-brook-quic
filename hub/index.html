Brook QUIC Client IWA (v1.23.0)

In-browser implementation of the Brook QUIC Client. Accepts inbound local SOCKS5 (--socks5 127.0.0.1:10808) and HTTP/HTTPS CONNECT (--http 127.0.0.1:8080) proxy requests, and tunnels them through authenticated, encrypted AES-256-GCM frames multiplexed over pure-browser QUIC (TLS 1.3 + Direct Sockets window.UDPSocket).

Running & Testing Isolated Web Apps in Chrome

1

Enable Chrome Flags

In Chrome (version 120+), navigate to these flags and set them to Enabled, then restart Chrome:

  • chrome://flags/#enable-isolated-web-apps
  • chrome://flags/#enable-isolated-web-app-dev-mode
2

Install via Dev Server Proxy

Navigate to chrome://web-app-internals in Chrome:

  1. Find "Install Isolated Web App from Dev Server".
  2. For Brook QUIC Client: Enter http://localhost:8083.
  3. For Listener: Enter http://localhost:8081.
  4. For Client: Enter http://localhost:8082.
3

Install via Signed Bundle (.swbn)

To test production Signed Web Bundles:

  1. Run npm run build to generate dist/*.swbn.
  2. In chrome://web-app-internals, use "Install Isolated Web App from Signed Web Bundle".
4

Test with CLI Proxy Command

Once Brook QUIC Client IWA is running in Chrome, test with curl:

  • curl -x socks5h://127.0.0.1:1080 https://httpbin.org/ip
  • curl -x http://127.0.0.1:8080 https://httpbin.org/ip
